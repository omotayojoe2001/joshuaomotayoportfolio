# Joshua Omotayo: Builder

BUILD A PREMIUM, DESIGN-FIRST PERSONAL PORTFOLIO FOR JOSHUA OMOTAYO

Build a highly polished, modern, design-first personal portfolio website for Joshua Omotayo, a Nigerian web developer, AI/technology educator, digital product builder, and entrepreneur.

This is NOT supposed to be a conventional developer portfolio.

The website should feel like a premium digital experience / personal brand website belonging to someone who designs and builds technology products, websites, AI systems, and digital experiences.

The first impression should be:

“This person is a serious builder.”

The second impression should be:

“This website itself is an example of his design and development ability.”

The website must communicate expertise through the quality of the experience rather than relying on excessive text.
